# 누룽이의 세계 — 촬영 모드

> **문서 상태: 초안(v0.1)**
> ★ = 07/08 문서에 근거가 있는 확정값. 표시 없는 값 = 제안값, 디렉터 확정 필요.

---

## 0. 왜 있는가

이 게임은 클리어가 아니라 **분위기**를 파는 게임이다 (기획서 §1). 플레이어가 "이 장면 예쁘다"고 느낀 순간을 **남길 수단**이 없으면 그 감정이 증발한다.

동시에 촬영 모드는 **개발 도구**이기도 하다:
- 트레일러를 게임 안에서 찍는다 ★ (08 H1: "게임 내 무비 모드로 촬영 → 편집은 CapCut")
- 품질기준 §2-1 스크린샷 테스트용 이미지를 뽑는다
- 07 §1 표: "촬영 모드·녹화 = Claude Code (카메라 제어·캡처·앨범)"

---

## 1. 진입과 종료

| | PC | Android |
|---|---|---|
| 진입 | **Tab** | 우하단 카메라 버튼 |
| 종료 | Esc / Tab | 뒤로 버튼 |

- 진입 시 **게임 시간 정지** (`Time.timeScale = 0`). 누룽이·NPC·바람이 그 자리에 멈춤
- 단, **절차적 레이어는 계속 돈다** — 귀가 흔들리고 눈을 깜빡인다 (기획서 §4-3). 완전히 멈추면 인형이 된다. `unscaledDeltaTime` 사용
- 추적 카메라(대형스크롤맵 §1-1)를 끄고 자유 카메라로 블렌드 (0.4초)
- 나가면 원래 카메라 위치로 되돌아옴

## 2. 카메라 제어

### 2-1. 조작

| 동작 | PC | Android |
|---|---|---|
| 좌우 이동(팬) | A/D, 마우스 드래그 | 한 손가락 드래그 |
| 상하 이동 | W/S | 한 손가락 드래그 |
| 줌 | 휠 | 두 손가락 핀치 |
| 회전(제한적) | Q/E | 두 손가락 회전 |
| 리셋 | R | 리셋 버튼 |

### 2-2. 이동 제한 ★

**자유롭게 두면 배경 그림의 뒷면과 맵 밖 빈 공간이 보인다.** 2D 배경 게임이므로 제한이 필수다.

| 축 | 범위 |
|---|---|
| X (좌우) | 챕터 `bounds` 안 (대형스크롤맵 §1-2) |
| Y (상하) | 지면 +0.5m ~ +8m |
| Z (앞뒤) | 기본 거리 ±6m. 배경 판(Z=+14)보다 앞을 넘지 못함 (대형스크롤맵 §2-1) |
| 피치 | 0° ~ 35° (기본 15°) |
| 요(좌우 회전) | **±20°만** — 더 돌리면 배경 판이 옆에서 보여 정체가 드러남 |
| 롤 | ±15° (기울인 구도용) |

### 2-3. FOV

- 기본 **28** (게임과 동일, 기술사양 §2-1)
- 조절 범위 **18 ~ 50**
- 18에 가까울수록 강한 망원 압축 → 이 게임 특유의 그림 같은 화면
- **50을 넘기지 않는다.** 광각이 되면 2D 배경 판의 왜곡이 드러난다

## 3. 프리셋·필터·프레임

### 3-1. 카메라 프리셋 ★ (07 §1: "프리셋·필터 고르기"가 사람 몫)

| 프리셋 | 구도 |
|---|---|
| 기본 | 게임과 동일 |
| 클로즈업 | 누룽이 얼굴, FOV 22, 거리 4m |
| 로우앵글 | 지면 +0.4m, 위를 봄 — 강아지 시점 |
| 와이드 | FOV 45, 거리 20m, 풍경 위주 |
| 뒷모습 | 누룽이 뒤 반신, 배경 강조 |
| 자유 | 제한만 지킴 |

### 3-2. 필터

- 시간대 LUT 6종 재사용 ★ (08 D2, D6) — 낮에 찍어도 노을 톤으로
- 필름 그레인 강약, 비네트 강약
- 흑백 / 세피아
- **종이 그레인은 항상 켜져 있다** (기술사양 §3-2) — 이 게임의 정체성이라 끄지 않음

### 3-3. 프레임 ★ (08 E7)

- 폴라로이드 / 스케치북 / 없음
- 프레임은 저장 이미지에 합성됨
- 폴라로이드 하단 여백에 **챕터 이름 + 날짜** 손글씨 폰트로 (08 E5)

### 3-4. 격자·가이드 ★ (08 E6)

- 3분할 격자
- **62% 지평선 선** — 개발용. 배경 정합 확인에 씀 (기술사양 §2-2, 품질기준 §2-1 6번)
- 안전 영역 표시

## 4. 촬영과 앨범

### 4-1. 촬영

- 셔터: Space / 화면 셔터 버튼
- 셔터음 ★ (08 F5)
- 저장 해상도: 화면 해상도 그대로, 최대 1920×1080 (Android 메모리)
- **UI는 찍히지 않는다** (격자·버튼 제외하고 렌더)

### 4-2. 저장 위치

```
PC:      %USERPROFILE%/Pictures/누룽이의세계/2026-09-14_153022.png
Android: /storage/emulated/0/Pictures/누룽이의세계/
```

- 게임 세이브와 **분리** (기획서 §8). 사진은 세이브 파일에 넣지 않고 폴더에 둔다
- 메타: `{chapter, x, time_of_day, preset, filter, taken_at}` 를 같은 이름의 `.json` 으로

### 4-3. 앨범

- 격자 썸네일, 챕터별 그룹
- 크게 보기, 삭제, **탐색기/갤러리에서 열기**
- 사진 개수 제한 없음 (썸네일은 캐시)

## 5. 무비 모드 ★ (08 H1)

트레일러를 게임 안에서 찍기 위한 모드.

### 5-1. 카메라 경로

1. 촬영 모드에서 카메라를 원하는 위치로 → **키 추가**
2. 여러 키를 찍으면 스플라인 경로가 생김
3. 키마다: 위치, 회전, FOV, 도달 시간, 이징(Ease In/Out)
4. **재생** → 카메라가 경로를 따라 움직임
5. 경로는 `docs/../movie_paths/<name>.json` 으로 저장·재사용

### 5-2. 시간 제어

- 게임 시간 배속: 0.25× / 0.5× / 1× — **슬로우모션이 트레일러의 절반이다**
- 무비 모드에서는 누룽이가 움직인다 (촬영 모드와 달리 정지하지 않음)
- 녹화 중 UI 전부 숨김

### 5-3. 녹화

| 플랫폼 | 도구 | 근거 |
|---|---|---|
| PC | **ffmpeg** (무료, 동봉) — 프레임 시퀀스 캡처 후 mp4 인코딩 | ★ 08 G6 |
| Android | **VideoKit** (~$100) — **정말 필요할 때만 구매** | ★ 08 G7, 08 J(M5) |

- PC 방식: 매 프레임 `ScreenCapture` → PNG 시퀀스 → ffmpeg 로 60fps mp4. **실시간 녹화가 아니라 오프라인 렌더**라 프레임 드랍이 없다. 트레일러 품질에는 이 방식이 낫다
- 출력: `build/movie/<name>.mp4`
- 편집은 **CapCut(무료)** ★ (08 H1)

**Android 녹화는 M5까지 미룬다** ★ (08 J). VideoKit $100은 PC 방식으로 트레일러가 안 나올 때만 쓴다.

## 6. 구현 순서

| 순서 | 항목 | 시점 |
|---|---|---|
| 1 | 자유 카메라 + 이동 제한(§2-2) + 격자(§3-4) | **M0** — 품질기준 §2-1 스크린샷 테스트에 필요 |
| 2 | 셔터·저장(§4-1, §4-2) | M0 |
| 3 | 프리셋·필터·프레임(§3) | M5 |
| 4 | 앨범(§4-3) | M5 |
| 5 | 무비 모드 경로·녹화(§5) | M6 (트레일러 직전) |

**1~2번을 M0에 먼저 만드는 이유**: 품질 판정용 스크린샷을 매번 수동으로 찍는 것보다, 격자와 62% 선이 나오는 카메라를 일찍 갖는 편이 M0/M1 판정을 훨씬 빠르게 한다.
