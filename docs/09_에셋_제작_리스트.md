## B. 배경 — 도형 → 손그림

| # | 필요한 파일 | 만드는 법 | 도구 |
|---|---|---|---|
| **B-1** | **스타일 앵커 30장** | 참조 영상 프레임(`scratchpad/frames/`)을 레퍼런스로 프롬프트 작성 → 생성 → 30장 선정 | **Higgsfield / Midjourney / Scenario** |
| **B-2** | **스타일 LoRA** | 앵커 30장 업로드 → 학습 (30분) | Scenario $29/월 또는 로컬 ComfyUI FLUX LoRA (0원) |
| **B-3** | 세그먼트 배치 생성 | 프롬프트 매트릭스 CSV → API 배치 (05 §4~5) | Scenario API / ComfyUI |
| **B-4** | 컷아웃 (나무·전봇대·화단·간판…) | 투명배경 생성 또는 **rembg/BiRefNet**으로 배경 제거 | 무료 |
| **B-5** | 바닥 타일 seamless | "seamless tile" 프롬프트, 킷당 1~2장 | Scenario |
| **B-6** | 하늘 원경 | 양끝 이어짐 프롬프트 | Scenario / Blockade Labs |

**고정 프롬프트 (05 §2-1 + 목업에서 확인한 톤)**:
```
flat pastel cartoon, warm cream palette (#EDE3D0 sky, #D9CCB4 wall, #A8AD7E foliage),
soft paper texture, bold brown outline (#6E5F49), no characters, no text,
front view slight high angle, horizon at 62% height,
flat ground in lower third, side margins for seamless tiling
```

### 참조 영상 기반 워크플로 (Higgsfield 등 영상 AI 활용)

1. **프레임 추출** — 이미 완료: `ffmpeg -vf fps=1/2` 로 8장 (`scratchpad/frames/f01~f08.png`)
2. **스타일 레퍼런스로 입력** — Higgsfield/Midjourney의 이미지 참조(`--sref`, style reference) 기능에 f01 투입
3. **캐릭터 제거 프롬프트** — 배경만 필요하므로 `no characters` 필수
4. **일관성** — 반드시 B-2 LoRA 학습 후 대량 생성 (07 §7: LoRA 없이 프롬프트만 쓰면 스타일이 흐트러짐)

⚠ **저작권**: 참조 영상은 타인 제작물(워터마크 "Pika"). **스타일 참고는 가능하나 프레임 자체를 게임에 넣거나 LoRA 학습 데이터로 직접 쓰지 않는다.** 앵커 30장은 우리가 생성한 이미지로만 구성하고, 출처를 `asset_sources.csv`에 기록한다.
