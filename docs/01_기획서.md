## 1. 한 줄 정의

> **강아지 누룽이가 되어, 손그림 같은 세계를 걷고 냄새 맡고 사진 찍는 게임.**

- 장르: 힐링 산책 / 탐색
- 목표: 승패 없음. "돌아다니는 것 자체가 기분 좋을 것"
- 세션 길이: 한 챕터 3~7분. 지하철에서 한 정거장
- 플랫폼: PC(Windows) 먼저 → Android ★ (07 §8)

**이 게임이 파는 것**: 클리어가 아니라 **분위기와 손맛**. 그래서 M0(룩) + M1(움직임)에 전체 공수의 40%를 씀 ★ (07 §4)

## 2. 플레이 루프

```
챕터 진입 → 걷는다 → 뭔가 눈에 띈다(냄새·소리·반짝임)
   → 다가가 상호작용 → 작은 반응(대사·소품 변화·수집)
   → 마음에 들면 촬영 → 챕터 끝점 도달 → 앨범/컬렉션 갱신
```

- **강제 목표 없음.** 끝점까지 그냥 걸어도 클리어
- 한 챕터에 **필수 1개 + 선택 3~6개**의 상호작용 지점
- 보상은 수치가 아니라 **수집품·사진·말풍선 한 줄**

## 3. 조작 ★

> 07 §3-4 가 "docs/기획서 §3 두 조작 방식 + 마지막 입력 규칙"으로 참조하는 절.

### 3-1. 두 조작 방식은 항상 동시에 살아 있다 ★

| 방식 | PC | Android | 성격 |
|---|---|---|---|
| **A. 직접 조작** | WASD / 방향키 / 게임패드 좌스틱 | 화면 좌하단 가상 조이스틱 | 아날로그, 즉각 |
| **B. 지점 이동** | 마우스 좌클릭 | 화면 탭 | 클릭한 바닥으로 걸어감 |

- 둘 중 하나를 고르게 하지 않는다. **켜져 있는 채로 공존**
- B의 클릭 이동이 그대로 Android 탭 이동이 됨 ★ (07 §8 1주차)

### 3-2. 마지막 입력 규칙 ★

**가장 최근에 들어온 입력이 제어권을 가진다. 이전 입력은 즉시 취소된다.**

```
상태: MoveTarget(B로 목적지까지 이동 중)
  → 사용자가 W를 누름
  → MoveTarget 즉시 취소, Direct 제어로 전환 (감속·정지 없이 자연스럽게 이어짐)

상태: Direct(스틱으로 이동 중)
  → 사용자가 바닥을 클릭
  → 현재 속도를 유지한 채 목적지를 향해 방향만 재설정
```

구현 규칙:
- 입력 소스마다 `lastInputTime` 을 기록, 큰 쪽이 이김
- 전환 시 **속도를 0으로 만들지 않는다.** 손맛이 끊기는 1순위 원인
- Direct 입력 데드존 0.15 미만은 입력으로 치지 않음 (스틱 드리프트로 목적지 이동이 취소되는 것 방지)

### 3-3. 이동 파라미터 (초안 — M1에서 손으로 조율)

★확정 2026-08-16: **걷기 = 2족, 질주 = 4족** (§4-1 하이브리드 보행)

| 값 | 걷기 (2족) | 질주 (4족) |
|---|---|---|
| 속도 | 2.2 m/s | 4.5 m/s |
| 가속 | 12 m/s² | 12 m/s² |
| 감속 | 16 m/s² | 16 m/s² |
| 회전 속도 | 540°/s | 720°/s |
| 스탠스 전환 | — | 내려가기/일어나기 각 0.3s, 이동 끊김 없음 |

- 질주 전환: Direct는 스틱 깊이 0.8 이상(키보드는 Shift) / 지점 이동은 목적지까지 6m 이상이면 자동 질주, 도착 2m 전 걷기로
- 질주 시작 = 앞으로 몸을 숙이며 4족으로. 질주 끝 = 일어나며 2족으로. **전환 중에도 속도는 유지** (§3-2와 같은 원칙)
- **가속·감속·회전 곡선이 곧 손맛.** 숫자를 바꿔가며 품질기준 §1-1 체크를 통과시키는 것이 M1의 전부

### 3-4. 그 외 입력

| 동작 | PC | Android |
|---|---|---|
| 상호작용 | E / 좌클릭(대상 위) | 대상 탭 |
| 촬영 모드 | Tab | 우하단 카메라 버튼 |
| 앉기·쉬기 | Space 길게 | 두 손가락 탭 |
| 카메라 좌우 살짝 | 마우스 우드래그 | 두 손가락 드래그 |

## 4. 누룽이의 표현

### 4-1. 모델

★확정 2026-08-16: **하이브리드 보행 강아지.** 평소엔 2족 직립(치비, 동물의 숲 주민 느낌), 질주하거나 지치면 4족.

- 2족 직립 치비 프로포션, 앞다리(팔)가 땅에 닿을 수 있는 길이 — 4족 전환 가능해야 함
- 저폴리 + 플랫 컬러 **3~4색** ★ (07 §3-1). 복잡한 텍스처는 쓰지 않음
- 머티리얼 슬롯: 털 / 귀 / 목걸이 / 코 ★ (08 A2)
- 리그: Unity **Generic** ★ (08 A3). 하나의 리그로 2족·4족 자세를 모두 커버 (스탠스는 리그가 아니라 애니메이션이 결정)
- 베이스 모델 조달: 로컬 ComfyUI 이미지→3D (1차 후보 확보됨, 2026-08-16) → 리토폴로지 8k 이하

### 4-2. 얼굴 = 텍스처 스왑 ★ (07 §3-2, 08 A8)

- 3D 조형·블렌드셰이프 **안 씀**
- 눈·입 스프라이트 시트 6종(기본/웃음/놀람/졸림/궁금/깜빡) × 좌우 → 얼굴 UV에 셰이더로 스왑
- 동물의 숲 / 페이퍼마리오 방식

### 4-3. 절차적 레이어 — 모든 경우에 필수 ★

> 07 §3-4 가 "docs/기획서 §4-3의 발 IK, 룩앳, 스프링본"으로 참조하는 절.
> 07 §3-2 표 3행: **"모든 경우에 반드시"**. 클립 품질을 가장 크게 끌어올리는 요소. 상세 판정은 품질기준 §1-4.

| # | 레이어 | 구현 | 목적 |
|---|---|---|---|
| 1 | **발 IK** | Unity Animation Rigging, 발마다 레이캐스트 (2족 스탠스 2발, 4족 스탠스 4발) | 경사·계단에서 발이 뜨거나 파묻히지 않음 |
| 2 | **머리 룩앳** | Multi-Aim Constraint, 목→머리 2단 분배 | 관심 대상을 쳐다봄. 살아 있다는 느낌의 핵심 |
| 3 | **스프링본** | UnityChan SpringBone (무료) ★ (08 A10) | 귀 2개, 꼬리 3~4마디가 움직임에 따라 흔들림 |
| 4 | **숨쉬기** | 가슴 본 스케일 사인파, 정지 시에만 | Idle이 멈춘 그림이 되지 않음 |
| 5 | **깜빡임** | 얼굴 시트 프레임 전환, 3~6초 랜덤 간격 | 위와 동일 |
| 6 | **스쿼시&스트레치** | 착지·점프 시 루트 스케일 ±8%, 0.12초 | 만화적 무게감 |

**규칙: 애니메이션 클립을 새로 넣을 때마다 이 6개가 그 위에서 정상 동작하는지 확인한다.**

### 4-4. 애니메이션 세트 (★확정 2026-08-16 하이브리드 보행으로 재편, 조달은 08 A4~A7)

| 묶음 | 스탠스 | 개수 | 내용 |
|---|---|---|---|
| 이동(기본) | **2족** | 6 | Idle / Walk / Turn L·R·180 / Start / Stop |
| 질주 | **4족** | 3 | Gallop / 4족 Start / 4족 Stop |
| 지침(연출) | **4족** | 2 | 터덜터덜 걷기(Trot 변형) / 헥헥 Idle — 오래 질주한 뒤 잠깐. 수치·게이지 없음(§12-2 실패 없음 유지) |
| **스탠스 전환** | 2↔4 | 2 | Down(2족→4족, 몸 숙이며) / Up(4족→2족, 일어나며) 각 0.3s |
| 점프 | 상황별 | 6 | 준비·상승·정점·하강·착지·실패착지 (걷다 점프 = 2족형, 질주 점프 = 4족형은 M1 이후 판단) |
| 자세·행동 | 혼합 | 22 | Sit, Lie, Stretch, Sniff(엎드려 4족), Push, Bite, Carry, Crawl, Shake, Bump … |
| 감정 | 2족 | 4 | Happy_wag / Curious / Sad / Excited |

**2족이 기본이 되면서 조달이 쉬워짐**: 2족 이동·감정은 휴머노이드 계열(Mixamo 등) 리타겟 후보가 생기고, 4족은 질주·지침만 필요해 Meshy 4족 라이브러리 의존이 줄어든다. 상세는 08 §L 반영 참조.

## 5. 세계와 챕터

### 5-1. 구조

```
세계 = 킷 25개 (골목, 공원, 지하철, 사무실, 해변 …)
킷 하나 = 챕터 여러 개
챕터 하나 = 세그먼트 6~12장이 좌우로 이어진 가로 스크롤 공간
```

- 킷 25 × 세그먼트 타입 25 = **배경 625장** ★ (08 C3)
- 챕터 총량: **200개는 목표가 아니라 상한.** M2에서 챕터 템플릿을 완성한 뒤, 1챕터 제작에 실제로 걸린 시간 × 남은 기간으로 재산정한다 (아래 §12 참조)

### 5-2. 공간 규칙

- **바닥은 3D, 배경 그림은 2D** ★ (07 §2-2)
- 누룽이는 바닥 위를 3D로 이동. 좌우로 길고 앞뒤(깊이)는 3~5m 정도로 얕음
- 배경 세그먼트는 카메라를 마주보는 판(billboard-ish quad)으로 뒤에 서 있음
- 컷아웃(건물·나무·소품)은 깊이별 3개 레이어로 배치해 시차(parallax) 생성

### 5-3. 시간대

- 아침 / 낮 / 노을 / 밤 (+ 비 / 눈)
- 같은 배경을 img2img로 변주 ★ (08 C4) + 조명·LUT 프리셋 6종 ★ (08 D2, D6)

## 12. 하지 않을 것 ★

> 07 §6-4, §7이 참조하는 절. **CLAUDE.md에도 그대로 들어감** ★ (07 §7)
> AI는 시키면 다 만들려 하므로, 이 목록은 방어선이다.

1. **전투 없음.** 적, 체력, 데미지, 사망
2. **실패 없음.** 게임오버, 타임어택, 리트라이
3. **대화 트리 없음.** 선택지, 분기, 호감도 수치
4. **인벤토리 시스템 없음.** 아이템 조합, 장비, 강화
5. **오픈월드 없음.** 챕터는 좌우로 이어진 길이지 자유 지형이 아님
6. **멀티플레이 없음.** 온라인, 랭킹, 친구
7. **과금 없음.** 광고, IAP, 시즌패스
8. **절차적 생성 없음.** 맵은 전부 손으로 배치 (에디터 툴로)
9. **커스터마이징 없음.** 옷 입히기, 색 바꾸기 (M6 이후 재검토)
10. **음성 없음.** 대사는 텍스트 + 강아지 소리만
11. **물리 퍼즐 없음.** 밀기는 연출이지 퍼즐 기믹이 아님
12. **번역 없음** (한국어만, 상업화 시 재검토)

**이 목록에 있는 것을 구현하라는 지시가 오면, 구현 전에 "이건 §12에 있는데 정말 할까요?"라고 되묻는다.**
