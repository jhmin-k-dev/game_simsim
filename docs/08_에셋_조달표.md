# 누룽이의 세계 — 에셋·컴포넌트 조달표
## 개발에 필요한 모든 것을 「어느 AI에서 만든다 / 어디서 산다 / 무료로 받는다」로 확정

> 원칙: **사람 외주 0을 목표**. 순서는 ① AI 생성 → ② 구매(에셋스토어·마켓) → ③ 무료 오픈소스 → ④ 그래도 안 되면 외주. 각 항목에 1순위와 대안, 비용, 파일 포맷, 게임에 넣는 방법을 적음. 툴 이름 옆 (유료)/(무료)/(구독) 표기. 가격은 2026년 중반 기준, 변동 가능 — 결제 전 확인.

**A4~A6 리타겟 참고**: 에셋스토어 강아지 팩을 사면 그 팩의 개 스켈레톤 → 누룽이 스켈레톤으로 옮겨야 함. Unity Generic 리그는 Humanoid처럼 자동 리타겟이 안 되므로 **Blender에서 본 이름 매핑 스크립트**(Claude Code)로 처리. 가장 확실한 길은 **A3를 Meshy로 리깅하고 A4~A6도 Meshy 라이브러리로** 받는 것 — 같은 리그라 리타겟이 필요 없음.

**품질이 부족하면**: 위 전부 해보고도 품질기준 §1-1 체크가 안 되면 그때만 이동 8클립 인간 외주 (100~200만 원). 그전엔 하지 않음.
