## A. 누룽이 캐릭터

### A-1. 【디렉터】 6방향 캐릭터 시트 — 3D 재생성용 ★우선순위 1

현 ComfyUI 모델은 스캔 특성상 표면이 거칠어서, 시트 기반으로 한 번 더 뽑으면 품질이 뜁니다.

**어디서**: Midjourney / Higgsfield / ComfyUI(SDXL 설치 후)
**프롬프트**:
```
character reference sheet of a chubby cream-colored puppy mascot,
chibi proportions, big round head, droopy ears, small red collar with gold tag,
standing upright on two legs, T-pose arms slightly out,
front view + side view + back view, consistent character,
flat pastel colors, bold brown outline, white background, no text
```
- 생성 5회 → 마음에 드는 1장 선택 → 저에게 주시면: ComfyUI Hunyuan3D → 리토폴로지 → 리깅까지 자동
- **4족 자세 시트도 1장**: 위 프롬프트에서 `standing upright on two legs` → `running on four legs like a dog, side view`

### A-2. 【디렉터】 얼굴 표정 시트 (01 §4-2 텍스처 스왑) ★우선순위 2

**어디서**: Recraft(무료 티어, 벡터 특화) / Scenario / Midjourney
**프롬프트**:
```
sprite sheet of cute simple dog facial expressions, 6 expressions in a row:
neutral, happy smile, surprised, sleepy, curious head-tilt, eyes closed blink,
minimal shapes — dot eyes, small round nose, simple mouth,
flat brown color on transparent background, bold outline, game asset, no text
```
- 6종 × 좌우 = 시트 1장. 눈·입만 있으면 됩니다 (얼굴 바탕은 3D)
- 받으면: 제가 UV 스왑 셰이더로 연결 + 깜빡임 이벤트(이미 구현됨)에 연동

### A-3. Meshy/Tripo 백업 경로 (ComfyUI 품질 부족 시에만, $20/월 1개월)

- A-1 시트를 Meshy "Image to 3D" 업로드 → 5회 생성 → 최선 선택
- 설정: Topology **Quad**, Target Polycount 30k, Symmetry On
- 리깅: 같은 사이트 "Auto-Rig" → 2족 휴머노이드형 선택 (하이브리드는 제가 Blender로 보완)

## B. 애니메이션

### B-1. Mixamo 무료 클립 (2족 기본 세트) — 【디렉터 30분】

**어디서**: mixamo.com (Adobe 무료 계정)
**방법**: 리깅 FBX(`unity/Assets/Art/Char/nurungi_rigged.fbx`)를 업로드 → Auto-Rigger 통과 시 아래 검색어로 클립 다운로드 (Without Skin, 30fps):

| 검색어 | 용도 (01 §4-4) |
|---|---|
| `Idle` (Breathing Idle) | 2족 Idle |
| `Walking` (Happy Walk) | 2족 Walk — 아장아장 느낌으로 |
| `Turn` (Left/Right Turn) | Turn L·R |
| `Jump` (Jump) | 점프 |
| `Sitting` (Sit To Stand 포함) | Sit |
| `Waving` | 인사 (감정) |
| `Excited` / `Happy` | Happy_wag 대용 |
| `Yawn` / `Stretching` | Stretch |

- 오토리거가 치비 비율을 거부하면 → 저에게 알려주세요, Blender 리타겟 스크립트로 처리합니다

### B-2. 4족 질주·전환 — Cascadeur 무료 【디렉터 1~2시간, 나중에】

- 스탠스 전환(Down/Up)·갤럽은 라이브러리에 없어 키포즈 3~4개를 잡아야 합니다
- 지금은 제가 만든 초안 클립(코드 생성)이 돌고 있으니 **M1 손맛 판정 후**에 해도 됩니다
