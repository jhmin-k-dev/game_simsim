## 2. 카메라

### 2-1. 기본 세팅 ★

| 값 | 설정 | 근거 |
|---|---|---|
| 투영 | **Perspective (원근)** | ★ 07 §2-1 |
| **FOV** | **28** | ★ 07 §2-1, §2-2 — 프로젝트 규칙으로 명시된 값 |
| 부감 각도 | **15°** | ★ 07 §3-3, §9 — 배경 생성 프롬프트와 동일해야 함 |
| 위치 | 누룽이 뒤 | ★ 07 §2-1 |
| 거리 | 12m (FOV 28의 망원감을 위해 멀리) | 초안 |
| 높이 | 지면 +3.2m | 초안 |
| Near / Far | 0.3 / 300 | 초안 |

**FOV 28은 이 게임의 정체성이다.** 망원 압축으로 배경 그림과 3D 바닥의 원근 차이가 눈에 덜 띄고, 미니어처 같은 인형극 느낌이 난다. **이 값을 바꾸면 배경 625장이 전부 어긋난다.** 변경은 디렉터 승인 필요.

### 2-2. 배경 정합

- 배경 그림의 지평선은 화면 세로 **62%** 위치 ★ (07 §3-3, §9)
- 카메라의 부감 15° + FOV 28 조합에서 지평선이 실제로 62%에 오도록 카메라 높이·피치를 맞춘다
- **검증 방법**: 격자 오버레이(08 E6)를 켜고 배경 앵커 1장을 붙여 지평선이 62% 선에 오는지 확인

### 2-3. SafeBoxCamera (원근 버전)

> 07 §3-4 가 "docs/기술사양 §2-3의 SafeBoxCamera 원근 버전"으로 참조하는 절.

**목적**: 캐릭터가 조금 움직일 때마다 카메라가 따라 흔들리면 멀미가 나고 배경이 계속 흐른다. 화면 중앙의 **안전 상자(safe box)** 안에서는 카메라가 가만히 있고, 캐릭터가 상자를 밀어낼 때만 카메라가 따라간다.

```
화면 좌표 기준 안전 상자
  ┌──────────────────────────┐
  │        (정지 영역)        │
  │   ┌──────────────┐       │   가로 ±18% (화면폭 기준)
  │   │      🐕      │       │   세로 ±10% (화면높이 기준)
  │   └──────────────┘       │
  │                          │
  └──────────────────────────┘
```

**"원근 버전"이 뜻하는 것**: 직교(ortho) 카메라라면 월드 거리 = 화면 거리라 계산이 단순하지만, 원근에서는 캐릭터의 카메라 거리(depth)에 따라 같은 월드 이동량이 다른 화면 이동량이 된다. 따라서 **월드 좌표가 아니라 뷰포트 좌표로 판정**한다.

구현 규칙:
1. 매 LateUpdate에서 캐릭터 위치를 `WorldToViewportPoint` 로 변환
2. 뷰포트 좌표가 안전 상자 안이면 → 카메라 목표 위치 갱신 안 함
3. 벗어나면 → 벗어난 축에 대해서만, 캐릭터가 상자 경계에 정확히 놓이는 카메라 위치를 역산해 목표로 삼음
4. 목표까지 **SmoothDamp** (가로 0.25s, 세로 0.45s — 세로를 느리게 해야 점프 때 화면이 덜 튐)
5. 점프 중에는 세로 추적을 0.6배로 더 눌러 붙임
6. **속도 기반 리드(lead)**: 이동 방향으로 최대 1.5m 앞을 미리 보여줌. 방향 전환 시 0.4s에 걸쳐 반영 (즉시 뒤집으면 화면이 요동친다)

Cinemachine 과의 관계는 **대형스크롤맵 §1-1** 참조 (Cinemachine의 Dead Zone 을 쓰되, 원근 보정과 리드는 커스텀 Extension 으로 얹는다).

### 2-4. 세로 모드 ★ (07 §8)

- 세로(9:16)에서는 가로 시야가 좁아지므로 카메라 거리를 1.35배로 늘린다
- 안전 상자는 가로 ±12% / 세로 ±14% 로 바꾼다
- **판정**: PC에서 창을 세로로 길게 늘려 확인 (폰 없이 검증 가능) ★ (07 §8)

1. 시간대 LUT (6종)
2. 종이 그레인 (스크린 오버레이, 강도 0.12, 해상도 비의존 — UV를 화면 픽셀 기준으로 고정할 것)

**종이 그레인이 이 게임의 "그림 느낌"을 만드는 결정적 요소.** 카메라가 움직여도 그레인이 같이 흐르면 안 된다 (화면 고정).

## 8. 코드 규칙

1. **한 파일 = 한 책임.** 500줄 넘으면 쪼갠다
2. **매직 넘버 금지.** FOV 28, 지평선 62% 같은 프로젝트 상수는 `Scripts/Config/GameConstants.cs` 한 곳에
3. **Update에서 GetComponent / Find 금지.** Awake에서 캐시
4. **씬에 하드코딩된 좌표 금지.** 챕터 배치는 전부 JSON에서 (대형스크롤맵 §4)
5. **public 필드 대신 `[SerializeField] private`**
6. 네임스페이스: `Nurungi.<영역>` (예: `Nurungi.Camera`)
7. 주석은 "왜"만. "무엇"은 코드가 말하게
8. 새 기능은 **회색 큐브 테스트 씬**에서 먼저 검증 후 본 씬에 붙임 ★ (07 §3-4)
