# 측정·판정 기록

품질기준 §3-4 규칙: 관문 판정과 성능 측정 결과를 여기에 남긴다.

## 형식

```markdown
## YYYY-MM-DD  [M0/M1/M2 관문 | 성능 측정]  n차
결과: (§1-1 체크는 번호별 ○/×, 성능은 수치)
판정: 통과 / 보류 / 실패
조치: 무엇을 바꿨는가
```
