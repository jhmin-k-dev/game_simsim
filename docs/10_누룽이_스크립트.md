# 누룽이 스크립트 (.nrg) — 문법으로 누룽이를 조작하기

> 좌표·이동 시간·모션·맵·초당 카메라 움직임을 **글로 써서 실행하고 눈으로 보는** 기능.
> 용도: ① 연출 확인 ② 무비 모드 트레일러 촬영(06 §5) ③ 손맛·카메라 테스트 재현
> 구현: `Assets/Scripts/Scripting/`

---

## 1. 여는 법

| 키 | 동작 |
|---|---|
| **F1** | 스크립트 콘솔 열기/닫기 |
| **F5** | 실행 |
| **F6** | 정지 (제어권을 플레이어에게 돌려줌) |

챕터 씬(StreetMock, GreyBox)에 콘솔이 들어 있다. 창 안에서 바로 고쳐 쓰고 F5를 누르면 즉시 반영된다.

---

## 2. 기본 규칙

- **한 줄 = 한 동작.** 위에서 아래로 순서대로 실행
- 줄 앞에 **`&`** 를 붙이면 **바로 앞 줄과 동시에** 실행 (누룽이가 걷는 동안 카메라를 미는 식)
- `#` 또는 `//` 뒤는 주석
- 숫자 뒤 `s`, `m`은 붙여도 되고 안 붙여도 됨 (`4s` = `4`)
- 좌표는 **`(x, z)`** — y(높이)는 바닥이 정한다 (03 §5 좌표계)

```
dog move (16, 0.3) in 4s
& cam pan 2 in 4s          ← 위와 동시에 실행
```

---

## 3. 명령 목록

### 맵

| 문법 | 뜻 |
|---|---|
| `map street_01` | 챕터 ID(또는 씬 이름)로 맵 전환. 로드가 끝날 때까지 기다린다 |

### 누룽이

| 문법 | 뜻 |
|---|---|
| `dog at (4, 0.3)` | 순간이동 |
| `dog move (16, 0.3) in 4s` | **4초에 걸쳐** 그 지점으로 (도착 시간 지정) |
| `dog move (16, 0.3) at 2.2` | **초속 2.2m로** 그 지점으로 (속도 지정) |
| `dog move to (16, 0.3) in 4s` | `to`는 있어도 없어도 같음 |
| `dog walk (…)` | `move`와 동일 (걷기 속도) |
| `dog run (40, 0.3) in 3.5s` | 질주 — **자동으로 4족 전환** |
| `dog face right` | 방향 전환. `right`/`left`/`camera`/`away` 또는 각도(`90`) |
| `dog jump` | 점프. **착지까지 기다린다**(약 0.67초) |
| `dog stance quad` | 스탠스 강제 전환. `quad`(4족) / `biped`(2족), 0.3초 |
| `dog motion sniff for 1.5s` | 모션 재생 — **클립 미구현이라 지금은 로그+대기만** (09 §A-6~A-10 대기) |

### 카메라

| 문법 | 뜻 |
|---|---|
| `cam fov 22 in 2s` | 화각. 기본 28 (02 §2-1) — **낮출수록 망원** |
| `cam distance 14 in 1s` | 누룽이와의 거리 |
| `cam height 3 in 1s` | 카메라 높이 |
| `cam pitch 6 in 1s` | 부감 각도 |
| `cam pan 3 in 5s` | **초당 3m로 5초간** 카메라만 이동 (추적 해제) |
| `cam follow` | 다시 누룽이 추적 |

`in <t>s`를 빼면 즉시 적용된다.

### 기타

| 문법 | 뜻 |
|---|---|
| `wait 1.5s` | 대기 |
| `say 산책 끝` | 콘솔·로그에 메시지 |

## 4. 예제

### 4-1. 기본 산책 컷

```
map street_01
dog at (4, 0.3)
dog face right

dog move (16, 0.3) in 4s
& cam pan 2 in 4s

cam follow
dog motion sniff for 1.5s
dog jump

dog run (40, 0.3) in 3.5s
& cam fov 22 in 3.5s

dog stance biped
say 산책 끝
```

### 4-2. 트레일러용 카메라 워크 (06 §5)

```
map street_01
dog at (6, 0.3)
dog face right

# 멀리서 천천히 밀고 들어가며 시작
cam distance 20 in 0s
cam fov 34 in 0s
dog move (30, 0.3) in 8s
& cam distance 11 in 8s
& cam fov 24 in 8s

# 정지 후 클로즈업
dog face camera
cam distance 5 in 1.5s
& cam fov 20 in 1.5s
wait 1s
```

### 4-3. 손맛 재현 테스트

```
# 같은 구간을 걷기/질주로 반복해 §1-1 체크 6·7번 확인
dog at (4, 0.3)
dog move (20, 0.3) at 2.2      # 걷기 속도
wait 0.5s
dog at (4, 0.3)
dog run (20, 0.3) at 4.5       # 질주 속도 — 스탠스 전환이 튀는지 본다
```

## 5. 동작 방식 (구현 메모)

- 스크립트 실행 중에는 `PlayerMover.ExternalControl = true` 로 **플레이어 입력이 차단**된다. 정지(F6)하거나 끝나면 자동 해제
- 이동은 **등속**이다 (가감속 없음) — 연출 타이밍이 정확히 맞아야 하기 때문. 가감속 손맛은 플레이어 조작에서만
- `CharacterController.Move`로 옮기므로 **벽·경사 충돌은 그대로 작동**한다
- 실행기(`ScriptRunner`)는 `DontDestroyOnLoad` — `map` 명령으로 씬이 바뀌어도 이어서 실행된다
- 카메라 값은 `SafeBoxCamera.ScriptDistance/ScriptHeight`로 덮어쓴다. 02 §2-1 기본값은 그대로 남는다

## 6. 아직 없는 것 (넣을 만한 것)

| 항목 | 메모 |
|---|---|
| `dog motion` 실제 클립 | 09 §A-6~A-10 애니메이션이 들어와야 함. 지금은 대기만 |
| `repeat 3 { … }` 반복 | 파서에 블록 문법 추가 필요 |
| `ease in/out` 지정 | 현재 이동은 등속, 카메라만 SmoothStep |
| `cam pan` 방향 | 지금은 +X만. `(x,y,z)` 벡터 받도록 확장 가능 |
| NPC·소품 조작 | 상호작용 시스템(01 §6) 구현 후 |
| `.nrg` 파일 로드 | 지금은 콘솔에 직접 입력. `run <파일명>` 추가 가능 |
| 녹화 연동 | 무비 모드(06 §5-3) ffmpeg 캡처와 묶으면 트레일러 자동 촬영 |
